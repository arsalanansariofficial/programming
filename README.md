# Programming

A growing collection of hands-on solutions and notes for algorithms, data structures, coding exercises, and SQL problems.

The repository is organized by language and platform so you can browse a topic, open a standalone solution, and study it in context.

## What you'll find

| Area                                           | Contents                                                                                                 |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| [Algorithms and data structures](./Algorithm/) | Implementations in C and TypeScript, with topics such as linked lists, trees, sorting, heaps, and graphs |
| [Exercism](./Algorithm/exercism/c/)            | C solutions to Exercism practice exercises                                                               |
| [LeetCode algorithms](./Algorithm/leetcode/)   | TypeScript solutions to selected coding problems                                                         |
| [LeetCode SQL](./SQL/leetcode/)                | SQL solutions to selected database problems                                                              |

## Repository map

```text
.
├── Algorithm
│   ├── dsa-c/          # Data structures and algorithms implemented in C
│   ├── dsa-typescript/ # Algorithm practice in TypeScript
│   ├── exercism/c/     # Exercism exercises in C
│   └── leetcode/       # LeetCode solutions in TypeScript
└── SQL
    └── leetcode/       # LeetCode SQL solutions
```

The numbered filenames make individual exercises easy to scan. For SQL problems, the filename is the problem number; for example, [`0175.sql`](./SQL/leetcode/0175.sql).

## Working with solutions

Solutions are kept as focused, standalone files rather than as one application. Open the relevant file to review its implementation and any examples included with it.

SQL solutions are individual queries. Run a query in a database engine that supports the syntax used by that problem; SQL dialects can vary between platforms and exercises.

## Notes

This is a personal learning collection, so solutions and coverage may evolve over time. Problem solutions are intended for study and practice; check the original exercise for its full requirements and constraints.
